# Mitt projekt (DT224_Anton_K-arefalk)
Detta är ett skolprojekt som handlar om att skapa sin egna webbsida med tre olika sidor som går igenom en introduktion, sina hobbies och en kontaktlista.
Ingen CSS eller Javascript användes för projektet, bara HTML och bilder.

## Publicering
Detta projekt har publicerats till tre olika webbsidor:
Netlify: [https://app.netlify.com/projects/dt224g-anton-k-refalk/overview](https://dt224g-anton-k-refalk.netlify.app)
Static.app: [dtgantonkarefalk.staticdomains.app](https://dtgantonkarefalk.staticdomains.app/index)

## Svar
Git add lägger till ändringarna på staging området medan Git commit sparar dessa ändringar på GitHub.
Eftersom man vill göra/testa ändringar på ett sätt som undviker att ändra mainkoden.
Den nya branchen slås ihop med mainkoden som gör att bara ändringarna läggs till.
Att pusha till GitHub laddar man upp koden till ett Repo medan att publicera den direkt gör så att webbplatsen blir helt tillgängligt på internet
Man skapar ett "gitignore" fil och lägger den dit så att filen ignoreras
